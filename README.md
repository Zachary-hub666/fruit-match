# 果趣连连看

一个水果主题的网页连连看小游戏，使用 HTML、CSS 和 JavaScript 制作。

## 游戏功能

- 三种难度：轻松、标准、挑战
- 倒计时、计分和通关时间奖励
- 提示、洗牌、暂停与继续
- 无可消除配对时自动洗牌
- 本机最高分记录
- 适配电脑与手机屏幕

## 游戏规则

点击两个相同水果，连接路线不超过两次转弯，
且中间没有其他水果，即可消除。路线可以经过棋盘外侧。

每消除一对获得 100 分。
使用提示扣除 20 分，洗牌扣除 50 分，最低为 0 分。
在倒计时结束前消除全部水果即可获胜。

## 本地运行

下载 index.html，用浏览器打开即可，无需安装依赖。
